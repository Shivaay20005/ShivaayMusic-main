# 🎵 ShivaayMusic v1.0.6

> **Native YouTube Player, Custom Branding, and UI Fixes.**

---

## ✨ What's New

### 🎥 Native YouTube Video Player
- **InAppWebView Integration**: Integrated a native WebView player directly into the app (Full Screen and Mini Player) replacing the laggy Hybrid Composition.
- **Aggressive Ad Blocking**: Custom JavaScript injection automatically hides YouTube ads, watermarks, UI controls, and the annoying "Tap to unmute" overlay.
- **Custom Branding**: Added a "SHIVAAY MUSIC" watermark overlay to the player for a premium, branded look.
- **Full Screen Controls**: Integrated native HTML5 Fullscreen functionality triggered by taps, with a dedicated back button.

### 🛠️ Bug Fixes & Improvements
- **Help & Support**: Added a new "Help & Support" button in the Settings menu for easy bug reporting via Email and Telegram.
- **YouTube API Tab Fix**: Fixed a critical issue where the homescreen stopped updating due to YouTube Music's new "Comments" tab breaking the hardcoded indexing.
- **Flutter Analyze Clean up**: Fixed unused imports and added missing `const` modifiers across the project for better performance.
- **APK Build Fix**: Resolved `PathExistsException` and Kotlin plugin compilation errors during the release build.

---
**Enjoy the smoother, ad-free music and video experience! 🚀**

## 📥 Installation

1. **UNINSTALL** any previous version of ShivaayMusic to avoid package conflicts.
2. Install the **1.0.5 APK** matching your device architecture (arm64-v8a is recommended for modern phones).
