
HOW TO UPDATE THIS CHANGELOG
============================
1. Whenever you make significant changes to the code, new features, or bug fixes, open this file.
2. Add a new section at the top with the current Date (YYYY-MM-DD) and Version Number.
3. List your changes in bullet points under categories like [Features], [Fixes], [installer], etc.
4. Be specific so you remember what changed when you look back.
5. Save this file before committing to Git.
