# 🎵 ShivaayMusic v1.0.2

> A massive update packed with new features, smarter personalization, and a fully rebuilt Music Room.

---

## ✨ What's New

### 🎙️ Music Room — Rebuilt

- Room stays alive in the **background** when you navigate away
- **Auto Host Migration** — if host leaves, the next senior member takes over automatically
- **Live Participants List** with role badges (Host / Listener)
- Chat input always visible, no more layout bugs

### 🧠 Made For You

- Analyzes your **top played songs** (last 7 days) and shows personalized picks on Home Screen

### 🔐 Google Sign-In

- **"Continue with Google"** added to login screen
- Fully integrated with Firebase Authentication

### 🔄 Cloud Sync

- Favorites and Search History **silently restore** on login — no manual action needed
- Liked songs sync to cloud in **real-time**

### 🛡️ Privacy & Security

- **App Lock** — Biometric / PIN / Windows Hello support
- **Incognito Mode** — listen without saving history

### ❤️ Double-Tap to Like

- Double-tap album art to **instantly love a song** with a heart animation

### 🖥️ Windows Improvements

- Native bottom-docked chat input
- Fixed media controls, system tray icon, and download paths

## 🐛 Key Fixes

- ✅ "Made For You" title showing as `madeforyou` — fixed
- ✅ Red Screen crash in Music Room during loading — fixed
- ✅ Ghost media controls stuck in notification shade — fixed
- ✅ App stuck on login screen (first-time users) — fixed
- ✅ Firestore permission errors after sign-out — fixed
- ✅ Android 12+ splash screen distortion — fixed
- ✅ Home Screen grey overlay crash on startup — fixed
- ✅ Favorites not restoring after re-login — fixed
- ✅ Crash on sign-out with empty queue — fixed
