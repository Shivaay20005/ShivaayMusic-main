FLUTTER REALTIME TESTING GUIDE (WITHOUT ANDROID STUDIO)
================================================

Purpose:
--------
This document explains how to test a Flutter app in REALTIME without using Android Studio,
using only VS Code, a physical Android device, or a web browser.

This setup is ideal for low-end or weak laptops.

------------------------------------------------
REQUIREMENTS
------------------------------------------------
1. Laptop (low-end supported)
2. VS Code
3. Flutter SDK (properly installed)
4. Android phone (Android 8+ recommended)
5. USB cable OR Wi-Fi (for wireless debugging)

------------------------------------------------
OPTION 1: REALTIME TESTING ON PHYSICAL ANDROID PHONE (RECOMMENDED)
------------------------------------------------

Why this is best:
- No emulator required
- Fast performance
- Real device behavior
- Hot Reload supported

Steps:
------
1. Enable Developer Options on phone
   - Settings → About Phone → Tap "Build Number" 7 times

2. Enable USB Debugging
   - Developer Options → USB Debugging → ON

3. Connect phone to laptop using USB cable

4. Verify device connection:
   Command:
     flutter devices

   If phone appears in the list, setup is correct.

5. Run Flutter app:
   Command:
     flutter run

6. Realtime development:
   - Edit code in VS Code
   - Press `r` in terminal for Hot Reload
   - App updates instantly on phone

Notes:
------
- This is TRUE realtime testing
- Faster than emulator
- Industry-standard workflow

------------------------------------------------
OPTION 2: REALTIME TESTING ON LAPTOP USING FLUTTER WEB
------------------------------------------------

When to use:
- Want live preview on laptop screen
- UI, navigation, logic testing
- No mobile hardware features required

Steps:
------
1. Enable web support:
   flutter config --enable-web

2. Ensure project setup:
   flutter create .

3. Run app in Chrome:
   flutter run -d chrome

Features:
---------
- Live preview in browser
- Hot Reload supported
- Very low system load

Limitations:
------------
- Mobile UI may differ slightly
- Camera, sensors, some plugins not supported

------------------------------------------------
OPTION 3: WIRELESS DEBUGGING (NO USB CABLE)
------------------------------------------------

Requirements:
-------------
- Android 11 or higher
- Same Wi-Fi network

Steps:
------
1. Enable Wireless Debugging in Developer Options

2. Pair device:
   adb pair IP:PORT

3. Connect device:
   adb connect IP:PORT

4. Run app:
   flutter run

Advantages:
-----------
- No cable needed
- Realtime testing maintained

------------------------------------------------
IMPORTANT TRUTHS
------------------------------------------------
- Android Studio is NOT required for Flutter
- Emulator is optional, not mandatory
- Physical phone is the best emulator
- VS Code + Flutter + Phone = Professional setup

------------------------------------------------
RECOMMENDED WORKFLOW (LOW-END LAPTOP)
------------------------------------------------
1. Write code in VS Code
2. Test UI/logic in Flutter Web (optional)
3. Test real behavior on physical phone
4. Use Hot Reload for speed
