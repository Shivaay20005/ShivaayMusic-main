=====================================================
SHIVAAYMUSIC & SHIVAAYTUBE: HOW IT WORKS (NO API LIMITS)
=====================================================

### 1. ShivaayMusic API Limit Kyu Hit Nahi Karti?

1. Official YouTube API ka use NAHI hota: 
Agar aap YouTube ki official "YouTube Data API v3" use karenge, toh YouTube aapko ek strict quota deta hai. Jaise hi limit cross hogi, app band ho jayegi. Par ShivaayMusic official API use nahi karti.

2. InnerTube API (Hidden API) ka Magic: 
ShivaayMusic directly YouTube Music ki internal API (jise InnerTube API kaha jata hai) ko call karti hai. App wahi same requests bhejti hai jo ek normal user ka Google Chrome browser ya official YouTube app bhejta hai. App apne aapko `WEB_REMIX` (YouTube Music Web) client bata kar request bhejti hai, isliye YouTube use ek regular browser samajhta hai.

3. Client-Side Requests (Sabse Bada Reason): 
Is app ka koi apna central server nahi hai. Jab bhi koi user gaana search karta hai, toh request direct uske khud ke phone (uske apne IP address) se YouTube ke server par jaati hai. Agar 1 lakh log bhi app chala rahe hain, toh YouTube ko lagta hai ki 1 lakh alag-alag aam log website khol kar baithe hain. Ek single IP se load nahi padta, isliye kabhi API limit hit ya block nahi hota.

ShivaayMusic me Code Kahan Hai:
- lib/services/music_service.dart ke `_sendRequest()` function me `WEB_REMIX` headers lagakar request jati hai.
- Video/Audio Stream ke liye pubspec.yaml me `youtube_explode_dart` package ka use kiya gaya hai jo video URLs ko decode karta hai (No Ads, Direct Mp4/M4a).

=====================================================
### 2. Apna "ShivaayTube" Website Kaise Banayein?
=====================================================

Website ke case me ek problem aati hai "CORS" (Cross-Origin Resource Sharing). Browser aapko website frontend se direct YouTube ko request nahi bhejne dega. Isliye aapko ek chhota backend server (Node.js) banana hoga jo `youtubei.js` package ka use karega. 

Yahan ek basic Node.js + HTML setup ka code hai:

-----------------------------------------
STEP 1: BACKEND SETUP (Node.js)
-----------------------------------------
Terminal me run karein:
npm init -y
npm install youtubei.js express cors


-----------------------------------------
STEP 2: BACKEND CODE (server.js)
-----------------------------------------
const express = require('express');
const cors = require('cors');
const { Innertube } = require('youtubei.js');

const app = express();
app.use(cors());

let yt;
async function initYouTube() {
    yt = await Innertube.create();
}
initYouTube();

// API 1: Search Videos (No API Key Required!)
app.get('/search', async (req, res) => {
    try {
        const query = req.query.q;
        const searchResults = await yt.search(query); 
        
        const videos = searchResults.videos.map(v => ({
            id: v.id,
            title: v.title.text,
            author: v.author.name,
            thumbnail: v.thumbnails[0].url
        }));
        res.json(videos);
    } catch (error) {
        res.status(500).json({ error: "Something went wrong" });
    }
});

// API 2: Get Direct Video Stream (No Ads!)
app.get('/play', async (req, res) => {
    try {
        const videoId = req.query.id;
        const info = await yt.getBasicInfo(videoId);
        const format = info.chooseFormat({ type: 'video+audio', quality: 'best' });
        
        res.json({ title: info.basic_info.title, streamUrl: format.url });
    } catch (error) {
        res.status(500).json({ error: "Could not fetch stream" });
    }
});

app.listen(3000, () => {
    console.log('ShivaayTube API Server running on port 3000');
});


-----------------------------------------
STEP 3: FRONTEND CODE (index.html)
-----------------------------------------
<input type="text" id="searchBox" placeholder="Search Videos...">
<button onclick="searchVideos()">Search</button>

<div id="results"></div>
<video id="player" controls width="600" autoplay></video>

<script>
    async function searchVideos() {
        const query = document.getElementById('searchBox').value;
        const response = await fetch(`http://localhost:3000/search?q=${query}`);
        const videos = await response.json();
        
        let html = '';
        videos.forEach(video => {
            html += `
                <div onclick="playVideo('${video.id}')" style="cursor: pointer; margin: 10px;">
                    <img src="${video.thumbnail}" width="200">
                    <h3>${video.title}</h3>
                </div>
            `;
        });
        document.getElementById('results').innerHTML = html;
    }

    async function playVideo(videoId) {
        const response = await fetch(`http://localhost:3000/play?id=${videoId}`);
        const data = await response.json();
        
        const player = document.getElementById('player');
        player.src = data.streamUrl; // Direct streaming without YouTube player/ads
        player.play();
    }
</script>

PRO TIP:
Agar backend server se zyada request jane pe YouTube aapke server ka IP block kare, toh developers Cloudflare Workers, Proxy Rotation, ya IPv6 pool ka use karte hain. Par choti ya personal project websites ke liye `youtubei.js` ekdum perfectly bina block hue kaam karta hai!
