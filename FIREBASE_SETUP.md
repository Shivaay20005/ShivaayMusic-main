# 🔥 Firebase Authentication & Cloud Firestore Setup Guide

This guide will help you integrate Firebase Authentication (for handling Login/Signup) and Cloud Firestore (for storing user data like Name, Phone, etc.) into the **ShivaayMusic** app.

---

## 🚀 Step 1: Create a Firebase Project

1.  Go to the [Firebase Console](https://console.firebase.google.com/).
2.  Click on **"Add project"**.
3.  Enter your project name (e.g., `ShivaayMusic`) and click **Continue**.
4.  You can disable Google Analytics for now (optional). Click **Create project**.
5.  Once created, click **Continue**.

---

## 📱 Step 2: Register Your App

1.  In the Firebase Project Overview page, click on the **Android Icon** (looks like a robot) to add an Android app.
2.  **Android package name**: Enter `com.shivaay20005.shivaaymusic` (Must match your `build.gradle` file).
3.  **App nickname**: Enter `ShivaayMusic` (Optional).
4.  **Debug signing certificate SHA-1**:
    - This is optional for Email/Password login, but recommended.
    - To get it, run this command in your project terminal:
      ```bash
      ./gradlew signingReport
      ```
    - Copy the `SHA1` from the `debug` section.
5.  Click **Register app**.

---

## 📥 Step 3: Add Configuration File

1.  Download the **`google-services.json`** file provided by Firebase.
2.  Move this file into your project's **`app`** folder configuration:
    - Path: `shivaaymusic-debugapp/app/google-services.json`
3.  Click **Next** in the Firebase console.

---

## 🛠 Step 4: Add Firebase SDKs

You need to update your project files to include Firebase.

### 1. **Project-level `build.gradle.kts`**

Add the Google Services plugin dependency:

```kotlin
plugins {
    // ... existing plugins
    id("com.google.gms.google-services") version "4.4.0" apply false
}
```

### 2. **App-level `app/build.gradle.kts`**

Apply the plugin and add the core dependencies:

```kotlin
plugins {
    // ... existing plugins
    id("com.google.gms.google-services")
}

dependencies {
    // Import the BoM for the Firebase platform
    implementation(platform("com.google.firebase:firebase-bom:32.7.0"))

    // Add the dependencies for Firebase products you want to use
    implementation("com.google.firebase:firebase-auth-ktx") // Authentication
    implementation("com.google.firebase:firebase-firestore-ktx") // Database
    implementation("com.google.firebase:firebase-analytics-ktx")
}
```

3.  Click **Sync Now** in Android Studio.

---

## 🔐 Step 5: Enable Authentication

1.  Go back to the [Firebase Console](https://console.firebase.google.com/).
2.  In the left menu, click **Build** > **Authentication**.
3.  Click **Get started**.
4.  Select **Native Providers** > **Email/Password**.
5.  Turn on the **Enable** switch.
6.  Click **Save**.

---

## ☁️ Step 6: Enable Cloud Firestore

1.  In the left menu, click **Build** > **Firestore Database**.
2.  Click **Create database**.
3.  Keep the default Location settings and click **Next**.
4.  Choose **Start in test mode** (This allows read/write access during development).
    - _Note: In production, you would update these Rules to be more secure._
5.  Click **Create**.

---

## 👨‍💻 Step 7: How to Use in Code

Once the setup is done, I will help you update `AuthScreen.kt` to use the following logic:

### **Singup Logic**

It will:

1.  Create a user in Firebase Auth using `auth.createUserWithEmailAndPassword(email, password)`.
2.  Get the unique `uid` generated by Firebase.
3.  Store the extra details (Name, Phone, Email) in Firestore under the `users` collection using that `uid`.

### **Login Logic**

It will:

1.  Sign in using `auth.signInWithEmailAndPassword(email, password)`.
2.  Fetch the user's details (Name, Phone) from Firestore using their `uid`.
3.  Save the session locally so they stay logged in.
