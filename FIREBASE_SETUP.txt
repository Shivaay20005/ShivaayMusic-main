Troubleshooting Common Issues
-------------------------------------------------------------------
1. "Google Sign-In is not enabled":
   - Go to Firebase Console -> Authentication -> Sign-in method -> Google. Toggle it ON.

2. "Developer Error" / Login Fails silently:
   - Usually means SHA-1 mismatch. Run `gradlew signingReport` again and verify the key matches what is in Firebase.
   - Ensure `google-services.json` is in `android/app/` and is the latest version.

3. "PlatformException(sign_in_failed, ...)"
   - Check internet connection.
   - Ensure you built the app (`flutter run`) after adding the new keys and json file. Sometimes a `flutter clean` is needed.
